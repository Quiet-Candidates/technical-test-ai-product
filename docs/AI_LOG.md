# AI log

We are not checking whether you used AI. We assume you did. We want to see **how**.

---

## 1. Tools

Which tools did you use, and for what?

## 2. How you worked

Describe your run through the app. What did you do by hand, and what did you get a machine to do?

## 3. The prompts

Paste the prompts that mattered, in order. Not all of them — the ones that changed what you found.

## 4. Where it was wrong

At least one concrete case: what the AI told you, why it was wrong, and how you caught it.

A tool that invents a bug is worse than no tool. Show us you can tell the difference.

## 5. What you would run on every release

If this app shipped every week, what part of what you just did would run without you?

Describe it. Build it if you can.
